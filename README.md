# lang-pack-bookmarks-go

A small bookmarks API used to exercise Octiq's Go language pack on a stack that is neither Gin + GORM nor Echo + sqlx.

| Area | Choice |
|---|---|
| HTTP | [chi](https://github.com/go-chi/chi) v5 on the standard `net/http` |
| Data access | [sqlc](https://sqlc.dev/): typed Go generated from SQL, over `database/sql` (no ORM) |
| Database | SQLite through the pure-Go `modernc.org/sqlite` driver (no cgo, no Docker) |
| Migrations | [goose](https://github.com/pressly/goose), SQL files embedded from `internal/database/migrations` as `NNNNN_name.sql` with `-- +goose Up` / `-- +goose Down` |
| Tests | [Ginkgo v2](https://onsi.github.io/ginkgo/) + [Gomega](https://onsi.github.io/gomega/) for the API; `testing` + testify for the database package |

## Run

```
PORT=8080 DB_PATH=bookmarks.db go run ./cmd/server
```

`DB_PATH` defaults to an in-memory database; `PORT` defaults to `8080`.

## Endpoints

| Method | Path | Notes |
|---|---|---|
| GET | `/health` | `{"status":"ok"}` |
| POST | `/bookmarks` | `{url, title}`; url an absolute http(s) URL, title 1-200 characters; `201` with the bookmark |
| GET | `/bookmarks` | every bookmark, oldest first; `[]` when empty |
| GET | `/bookmarks/{id}` | `400` for a bad id, `404` for a missing bookmark |

Every error body is `{"error": "<message>"}`, including chi's own 404 and 405.

## Generated code

`internal/database/dbgen` is generated by sqlc from the schema in `internal/database/migrations` and the queries in `internal/database/queries`. Change those, then run:

```
go generate ./...
```

Never edit `dbgen` by hand. A schema change is a new migration file; existing migrations are never edited.

## Conventions

- Handlers pass `r.Context()` to every query.
- API tests are Ginkgo specs (`Describe` / `It` / `DescribeTable`) against the real router built by `newTestRouter()`, which opens a fresh migrated in-memory database.
- `gofmt -l .` prints nothing; `go build ./...`, `go vet ./...` and `go test ./...` pass; `go generate ./...` leaves no diff.
